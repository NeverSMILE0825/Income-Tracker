Txn Fee Sum

Adds the Etherscan Txn Fee column from a start block through an end block. Every fee is gas price × gas used, in wei, so the total matches Etherscan to the last digit. List cells use the same shortened decimals as the website. Hover a fee or amount for the full value.

A free key is enough. Create one at etherscan.io/apidashboard. Several keys, separated by spaces, are used in turn. The key stays in this browser. Historical blocks are cached on this PC, so the next identical run does not call Etherscan again. On the free plan, a few hundred thousand transactions usually take a couple of minutes.

Incoming rows are listed by Etherscan too, but that fee was paid by the sender. Choose outgoing when you want only the fees this address paid.
